Задание 1
Цель работы:

Разработка скрипта на языке Python для автоматизированного скачивания записей GenBank для двух заданных видов ( Brassica oleracea и Solanum lycopersicum) с сайта NCBI, объединения этих записей в один файл формата GenBank и проверки наличия не менее 10 кодирующих областей (CDS). Сформированный файл GenBank служит исходными данными для последующего анализа в других заданиях.
Задачи:

1. Скачивание записей GenBank: Реализовать функцию для скачивания указанного количества GenBank записей для заданного вида с использованием библиотеки Biopython и NCBI Entrez API.
2. Обработка ошибок: Предусмотреть обработку возможных ошибок при скачивании записей (например, отсутствие соединения, неверный запрос, отсутствие результатов).
3. Объединение записей: Объединить скачанные записи для двух видов в один список (объект Biopython).
4. Проверка количества CDS: Проверить, содержит ли объединенный список записей не менее 10 CDS. Вывести предупреждение, если это условие не выполняется.
5. Сохранение в файл: Сохранить объединенный список записей в файл формата GenBank.
6. Оптимизация и документирование кода: Обеспечить читаемость, организованность и понятность кода, добавив комментарии и разбив код на функции.
Алгоритмы и инструменты:

1. NCBI Entrez API: Используется для поиска и скачивания записей GenBank. Для поиска используется функция Entrez.esearch, для скачивания - Entrez.efetch.
2. Biopython: Библиотека Python для работы с биологическими последовательностями. Используется для парсинга записей GenBank (функция SeqIO.parse) и записи в файл GenBank (функция SeqIO.write).
3. Циклы for: Используются для итерации по записям и признакам (features) внутри записей GenBank.
4. Условные операторы if: Используются для проверки условий (например, наличие CDS, количество записей, наличие ошибок).
5. Обработка исключений try...except: Используется для перехвата и обработки возможных ошибок во время выполнения скрипта.
6. Функции: Код разбит на функции для модульности и повторного использования.
Ошибки и их исправления:
Недостаточное количество CDS: Изначально скрипт не проверял, содержит ли результирующий файл достаточное количество CDS. Добавлена проверка количества CDS после объединения записей. Если количество CDS меньше 10, выводится предупреждение, и пользователю рекомендуется увеличить количество скачиваемых записей или выбрать другие записи.
Отсутствие проверки на пустые результаты: Первоначально не было проверки на случай, если поиск не возвращал результатов (пустой список ids). Добавлена проверка, и в случае пустого списка выводится предупреждение, и функция возвращает пустой список, чтобы избежать ошибок в дальнейшем.
Не указан email: В Entrez API обязательно указывать свой email адрес. Изначально код не содержал напоминания об этом. Добавлено напоминание и пояснение в комментариях.
Вывод:

Разработанный скрипт успешно выполняет поставленные задачи: скачивает записи GenBank для двух видов, объединяет их в один файл и проверяет наличие необходимого количества CDS. Благодаря добавлению обработки ошибок, проверки количества CDS и улучшенному форматированию кода, скрипт стал более надежным, удобным в использовании и читаемым. Полученный файл GenBank может быть использован в качестве исходных данных для последующих заданий, связанных с анализом биологических последовательностей. В дальнейшем можно расширить функциональность скрипта, добавив возможность фильтрации записей по различным критериям, выбора конкретных генов или аннотаций.

Задание 2
Цель работы

Целью работы является разработка скрипта на языке Python, который будет читать файл GenBank, вычислять GC-состав каждой последовательности и выводить их в порядке возрастания GC-состава.
Задачи
• Чтение файла GenBank: Реализовать функцию для чтения файла GenBank с использованием библиотеки Biopython.
• Вычисление GC-состава: Реализовать функцию для вычисления GC-состава каждой последовательности с использованием библиотеки Biopython.
• Сортировка последовательностей: Отсортировать последовательности по возрастанию GC-состава.
• Вывод результатов: Вывести отсортированные последовательности с указанием их идентификатора, описания и GC-состава.
• Обработка ошибок: Предусмотреть обработку возможных ошибок при чтении файла и вычислении GC-состава.
Алгоритмы и инструменты

• Biopython: Использована библиотека Biopython для работы с биологическими последовательностями, в частности для чтения файла GenBank (SeqIO.parse) и вычисления GC-состава (GC).
• Функция GC(): Функция из Bio.SeqUtils для вычисления GC-состава.
• Функция sorted():  Стандартная функция Python для сортировки списка последовательностей на основе их GC-состава. В качестве ключа сортировки используется лямбда-функция, возвращающая GC-состав последовательности.
• Обработка исключений try...except: Использована для перехвата ошибок, таких как отсутствие файла.
Ошибки и их исправления

• Отсутствие обработки ошибок: Первоначальная версия скрипта не содержала обработки ошибок, что могло приводить к аварийному завершению при отсутствии файла. Исправлено добавлением блока try...except для обработки исключения FileNotFoundError и вывода соответствующего сообщения.
• Неэффективное вычисление GC-состава:  В ранних версиях GC-состав вычислялся непосредственно в цикле сортировки, что было неэффективно. Исправлено путем добавления вычисленного GC-состава как атрибута к каждой записи, что позволило избежать повторных вычислений.
Вывод

Разработанный скрипт успешно решает задачу сортировки последовательностей GenBank по GC-составу. Он эффективно читает файл GenBank, вычисляет GC-состав каждой последовательности и выводит их в отсортированном порядке. Скрипт также включает обработку ошибок для обеспечения его надежности и устойчивости к различным сценариям использования. Код хорошо структурирован и документирован, что облегчает его понимание и модификацию.

Задание 3
Цель работы

Целью работы является разработка скрипта на языке Python, который будет читать файл GenBank, находить все кодирующие области (CDS) в каждой записи, транслировать их в белковые последовательности и выводить информацию о каждой трансляции, включая идентификатор записи, описание, положение CDS и саму транслированную последовательность.
Задачи
• Чтение файла GenBank: Реализовать функцию для чтения файла GenBank с использованием библиотеки Biopython.
• Поиск кодирующих областей (CDS): Реализовать поиск CDS в каждой записи GenBank.
• Извлечение последовательности CDS: Извлечь последовательность нуклеотидов, соответствующую найденной CDS.
• Трансляция CDS в белок: Транслировать последовательность нуклеотидов в аминокислотную последовательность (белок) с использованием Biopython.
• Вывод информации о трансляции: Вывести идентификатор записи, описание, положение CDS и транслированную последовательность белка.
• Обработка ошибок: Предусмотреть обработку возможных ошибок при чтении файла, поиске CDS и трансляции.
. Алгоритмы и инструменты

• Biopython: Использована библиотека Biopython для работы с биологическими последовательностями, в частности для чтения файла GenBank (SeqIO.parse), извлечения последовательности CDS (feature.extract) и трансляции последовательности (cds_seq.translate).
• Цикл for: Используется для итерации по записям GenBank и по признакам (features) внутри каждой записи, для поиска CDS.
• Условный оператор if: Используется для проверки типа признака (feature.type == "CDS").
• Функция translate(): Функция из Bio.Seq для трансляции нуклеотидной последовательности в аминокислотную.
• Обработка исключений try...except: Используется для перехвата ошибок, таких как отсутствие файла, ошибки трансляции и т.п.
Ошибки и их исправления

• Отсутствие обработки ошибок: Первоначальная версия скрипта не содержала обработки ошибок, что могло приводить к аварийному завершению при отсутствии файла или ошибках трансляции. Исправлено добавлением блоков try...except для обработки исключений FileNotFoundError и общих Exception в процессе трансляции.
• Некорректное положение CDS: В ранних версиях, возможно, некорректно обрабатывалось положение CDS. Убедился, что start и end извлекаются правильно, и feature.extract используется для правильного извлечения последовательности.
• Отсутствие указания полярности цепи: Ранее не указывалась полярность цепи ДНК. Добавлено явное указание полярности ("Positive" или "Negative").
• Остановка трансляции при стоп-кодоне: Добавлен параметр to_stop=True в функцию translate(), чтобы трансляция останавливалась при первом стоп-кодоне.
Вывод

Разработанный скрипт успешно решает задачу трансляции кодирующих областей (CDS) из файла GenBank. Он эффективно читает файл GenBank, находит CDS, транслирует их в белковые последовательности и выводит всю необходимую информацию о каждой трансляции. Скрипт также включает обработку ошибок для обеспечения его надежности и устойчивости к различным сценариям использования
