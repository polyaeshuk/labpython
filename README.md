Задание 1
1.	Цель работы.
Детальное исследование взаимосвязи между содержанием алкоголя (alcohol) и пролином (proline) в наборе данных Wine. Основная цель заключается в создании и анализе диаграммы рассеяния, чтобы визуально оценить возможность разделения различных классов вина (target) на основе значений этих двух признаков.
2.	Задачи
- Загрузить набор данных Wine из библиотеки scikit-learn.
- Изучить структуру набора данных: типы данных, количество образцов, количество признаков.
- Извлечь признаки 'alcohol' и 'proline' из набора данных.
- Извлечь целевую переменную 'target', представляющую классы вина.
- Построить диаграмму рассеяния с использованием 'alcohol' и 'proline' в качестве координат.
- Раскрасить точки на диаграмме рассеяния в соответствии с их классом.
      3.  Инструменты и алгоритмы
- Язык программирования python
- Библиотека scikit-learn (sklearn): Для загрузки и подготовки данных.
- Библиотека matplotlib (matplotlib.pyplot): Для создания диаграммы рассеяния.
*Функция load_wine() из модуля sklearn.datasets предназначена для загрузки встроенного набора данных Wine в scikit-learn. Этот набор данных содержит информацию о химических характеристиках различных образцов вина и их классификации по сорту (культивару).
*Функция scatter() из модуля matplotlib.pyplot используется для создания диаграмм рассеяния (scatter plots). Диаграмма рассеяния отображает точки на плоскости, где каждая точка соответствует одному образцу данных, а координаты точки определяются значениями двух признаков.
        4.  Ошибки и их исправления
* Ошибка: Изначальное использование цветовой карты, которая плохо различает классы.
  • Исправление: Проведено тестирование различных цветовых карт (viridis, plasma, magma, cividis, coolwarm) и выбрана карта viridis как наиболее подходящая для четкого разделения классов.
* Ошибка: Точки на диаграмме перекрывались, затрудняя визуальную оценку плотности данных.
  • Исправление: Добавлен параметр alpha (прозрачность) в функцию plt.scatter(), что позволяет видеть перекрывающиеся точки и лучше оценивать плотность данных.
* Ошибка: Отсутствие подробных подписей осей и заголовка, что затрудняло понимание графика.
  • Исправление: Подписи осей и заголовок графика были дополнены, чтобы предоставить более полную информацию о представленных данных.
       5. Выводы
• Была успешно построена и проанализирована диаграмма рассеяния для набора данных Wine, демонстрирующая взаимосвязь между содержанием алкоголя и пролина.
• Визуальный анализ показал, что классы вин частично разделены по этим признакам, но для более точной классификации необходимо учитывать и другие признаки.
• Были получены знания о важности выбора цветовой карты, прозрачности точек и данных и способов представления результатов имеет решающее значение для правильной интерпретации и принятия решений.
