1.	Цель работы:

Разработка и реализация программы на языке Python, генерирующей все перестановки заданного множества натуральных чисел и выводящей их в заданном формате. Цель достигается путем использования стандартной библиотеки Python и эффективной обработки входных и выходных данных.
2.	Задачи
Описать алгоритм генерации всех перестановок чисел от 1 до n. Обеспечить корректный и информативный вывод результатов, включающий общее число перестановок и список всех перестановок в нужном формате (каждая перестановка на отдельной строке, числа в перестановке разделены пробелами).
 Провести тестирование программы с различными входными данными и исправить обнаруженные ошибки
3.	Инструменты и алгоритмы
Функция itertools.permutations() в Python реализует алгоритм для генерации всех возможных перестановок элементов из заданного итерируемого объекта (например, списка, кортежа, строки). Она базируется на рекурсивном алгоритме.
  1.Базовый случай (рекурсия):

  • Если входной итерируемый объект пуст, то возвращается одна перестановка - пустой        список.

  2. Рекурсивный шаг:

• Для каждого элемента element во входном итерируемом объекте:
  • Создается новый итерируемый объект remaining_elements, содержащий все элементы исходного объекта, кроме element.
  • Рекурсивно вызывается permutations(remaining_elements) для получения всех перестановок оставшихся элементов.
  • Для каждой перестановки sub_permutation, полученной из рекурсивного вызова, создается новая перестановка, путем добавления element в начало sub_permutation.
  • Все полученные таким образом перестановки собираются вместе.
4.	Ошибки и их исправления
• Ошибка 1 (Первоначальная): Неправильный вывод списка (отсутствие пробелов).
    * Описание: Первоначально программа выводила перестановки в виде одного длинного числа без пробелов, например, "123".
    * Исправление: Использован синтаксис print(*perm) для распаковки кортежа и вывода элементов с пробелами.

• Ошибка 2 (Возможная): Переполнение при больших значениях n.
    * Описание:  При значениях n больше 7 программа может выполняться слишком долго из-за экспоненциального роста числа перестановок.
    * Решение: (Решение не реализовано в коде, но указано как возможное улучшение). В реальных задачах можно рассмотреть ограничение на максимальное значение n или использовать генераторы для ленивой обработки перестановок (не хранить все перестановки в памяти одновременно).
5.	Выводы
Программа эффективно использует стандартную библиотеку Python и обеспечивает корректный вывод результатов. Обнаруженные ошибки были устранены.
