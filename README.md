Лаба 2 Вариант 3
1.	Цель работы
Разработка программы, вычисляющей количество возможных мРНК-последовательностей, кодирующих заданную аминокислотную последовательность (протеин), с учетом вывода остатка от деления этого количества на 1,000,000 для предотвращения переполнения.
2.	Задачи
- Проанализировать таблицу кодонов и определить количество кодонов, соответствующих каждой аминокислоте.
-  Спроектировать алгоритм для вычисления общего количества возможных мРНК-последовательностей, кодирующих заданную белковую последовательность, учитывая множественность кодирования и стоп-кодоны
- Реализовать модульную арифметику для предотвращения переполнения при работе с большими числами, вычисляя остаток от деления результата на 1,000,000.
-  Провести тестирование программы с различными аминокислотными последовательностями и исправить обнаруженные ошибки.
     3.  Инструменты и алгоритмы
* Язык программирования python
 * Алгоритм подсчета мРНК-последовательностей: Последовательное умножение количества кодонов, соответствующих каждой аминокислоте в заданной последовательности, с учетом стоп-кодонов.
    * Модульная арифметика: Вычисление остатка от деления промежуточных результатов на 1,000,000 после каждой операции умножения. Использование свойства (a * b) mod m = ((a mod m) * (b mod m)) mod m.
4.	Ошибки и их исправления
Ошибка : Отсутствие учета стоп-кодонов.
    * Описание:  В первой версии программы не учитывалось наличие стоп-кодонов в конце мРНК-последовательности.
    * Исправление: Добавлено умножение результата на количество стоп-кодонов (3) с последующим взятием остатка от деления на MOD.
5.	Выводы
В результате выполнения лабораторной работы была успешно разработана и реализована программа на языке Python, которая вычисляет количество возможных мРНК-последовательностей, кодирующих заданную аминокислотную последовательность, и выводит остаток от деления этого количества на 1,000,000. Применение модульной арифметики позволило избежать переполнения при работе с большими числами. Ошибки, связанные с неправильным количеством кодонов и отсутствием учета стоп-кодонов, были устранены.
